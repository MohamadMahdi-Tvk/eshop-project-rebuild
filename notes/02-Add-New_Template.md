# static files:

برای افزودن فایل های استاتیک مثل سی اس اس ها، جاوااسکریپت ها و ... میبایست ابتدا در فایل ستینگ آدرس آنها را مشخص کنیم:

```
STATICFILES_DIRS = [
    BASE_DIR / 'static'
]
```
حال در ریشه ی پروژه میایم فولدر استاتیک رو ایجاد کرده و تمامی فولدر های مربوط به سی اس اس و ... رو داخلش
قرار میدهیم.

### دسترسی به فایل ها از طریق یوآرال مرورگر:
ما میتونیم از طریق یوآرال مرورگر هم به این فایل های استاتیک دسترسی داشته باشیم مثلا

http://127.0.0.1:8000/static/css/main.css

http://127.0.0.1:8000/static/images/404/404.png

### ctrl + f:
چون از قالب آماده استفاده میکنیم، آدرس دهی های فایل های استاتیک درست نیست، به همین دلیل باید آدرس جدید رو به رفرنس های
فایل اچتی ام ال معرفی کنیم، به همین دلیل ساده ترین راه استفاده از این دستور برای عملیات جایگزینی آدرس جدید به آدرس قدیمی است

1. css/  => در کادر اول - برای سی اس اس ها
2. /static/css/  => در کادر دوم - برای سی اس اس ها
3. js/  => در کادر اول - برای جاوااسکریپت ها
4. /static/js/  => در کادر دوم - برای جاوااسکریپت ها
5. images/  => در کادر اول - برای تصاویر
6. /static/images/  => در کادر دوم - برای تصاویر

آدرس کادر دوم با آدرس کادر اول جایگزین یا ریپلیس میشود
