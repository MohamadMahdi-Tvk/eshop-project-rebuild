# Django Render Partial

برای مدیریت بخش های مختلف صفحات مثل لایوت اصلی که دیتای داینامیک دارند از این پکیج استفاده میکنیم.

داکیومنت مربوط به آن:
https://pypi.org/project/django-render-partial/

مراحل ایجاد یک پارشیال ویو:

1. pip install django-render-partial -> نصب پکیج از طریق ترمینال
2. 'django_render_partial' -> افزودن به اینستالد اپ های فایل ستینگ پروژه
3. ایجاد یک فایل پارشیال درون فولدر تمپلیت و شیرد، مثلا برای قسمت هدر سایت به نام site_header_component.html
4. معرفی آن در فایل ویو:

```
  def site_header_component(request):
    return render(request, 'shared/site_header_component.html', {})
```

ما میتونیم ابتدای همین فانکشن هم به دیتابیس رکوئست بزنیم و بفرستیم برای کانتکس که سومین ورودی فانکشن رندر است

5. یکی از روش ها، اضافه کردن به یوآر ال هاست:
   `path('site-header', views.site_header_component, name='site_header_partial')`

6. در بالای صفحه ی لایوت خود باید رندر پارشیال لود شود، برای اینکه بشه از پکیج استفاده کرد؛ پس:
   `{% load render_partial %}`

7. حال در جایی که قرار هست آن پارشیال نمایش داده شود، مثلا در بخش هدر:
   `{% render_partial 'site_header_partial' %}`
   site_header_partial: اسمی که در یو آر ال به آن اختصاص داده ایم

اما این روش یک مشکلی دارد؛ چون ما از طریق آدرس زیر میتوانیم به محتویات آن دسترسی داشته باشیم که این خوب نیست
http://127.0.0.1:8000/site-header

راهکار خوب، این هست که بیایم به رندر پارشیال، بجای آدرس، اون فانکشن در ویو رو ارسال کنیم و یوآر الی هم که تعریف کرده ایم
در بخش 5 برداریم یعنی:

`{% render_partial 'home_module.views.site_header_component' %}`

### Django Render Partial Or Include Tag?

برای صفحاتی که قرار هست دیتاهای داینامیک داشته باشند باید از جنگو رندر پارشیال استفاده کنیم ولی برای صفحاتی که قرار نیست
دیتای داینامیکی داشته باشند، مثل بخش های معرفی فایل های جاوااسکریپت و سی اس اس ها میایم از اینکلود تگ خود جنگو استفاده
میکنیم. پس بطور کلی، در پروژه ما هدر و فوتر بعنوان یک پارشیال ویو یا کامپوننت در همه ی صفحات باید باشند و حتی میتوانند
دیتا داشته باشند، و دیتا رو بصورت کانتکس به رندر پاس داده و در فایل ویو از آن استفاده کنیم

### component:

به بخش هایی از صفحه که بصورت جداگانه مدیریت میشوند، کامپوننت میگویند.

### Shift + f6:

برای تغییر نام دادن فایل ها در سمت چپ محیط پایچارم است.
