# Django Forms - Part 3

## {{ contact_form }} :

ما با این دستور در صفحه اچتی ام ال، کل فرم را نمایش میدادیم ولی میتوان این کار را نکرد و اگر همین دستور را بعدش . قرار
بدیم، میتونیم بیایم و آن اینپوت هایی که داریم را جداگانه نمایش دهیم؛ مثلا میتونیم بیایم در صفحه فقط لیبل تگ اینپوت و خود
اینپوت را داشته باشیم و نمایش بدیم:

`{{ contact_form.full_name.label_tag }}`
`{{ contact_form.full_name }}`

با دستور زیر هم میتوان ارور های مربوط به اینپوت را نمایش دهیم:

`{{ contact_form.full_name.errors }}`

## attrs :

با استفاده از ویجت و سپس این دستور میتونیم اتربیوت برای اینپوت هامون درنظر بگیریم؛ بطور مثال با همین روش میتونیم اتربیوت
کلاس و سپس کلاس های بوت استرپ به اینپوت خود اعمال کنیم؛ یعنی کلاس، در زمانی که اینپوت رندر شد، به آن اینپوت پاس داده
شود؛ یا اتربیوت پلیس هولدر بهش پاس بدیم:

```
widget=forms.TextInput(attrs={
    'class': 'form-control',
    'place-holder': 'نام و نام خانوادگی'})
```

## قرار دادن شرط درون تگ ها:

با ایف میتوان درون تگ شرط گذاشت، مثلا اگر اروری رخ داد، رنگ لیبل و رنگ متن ارور قرمز شود:

```
<div class="col-md-6 form-group {% if contact_form.full_name.errors %} text-danger {% endif %}">
    {{ contact_form.full_name.label_tag }}
    {{ contact_form.full_name }}
    {{ contact_form.full_name.errors }}
</div>
```
