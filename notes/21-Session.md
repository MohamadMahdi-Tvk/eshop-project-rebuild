# Session

نحوه ی واکشی اطلاعات سشن رو میخواهیم بررسی کنیم، برای نمایش و واکشی اطلاعات سشن، از ویوی جزئیات محصول استفاده میکنیم؛
یعنی ما اول محصول رو بدست میاریم سپس با استفاده از کلید آن سشن به آیدی آن محصول دسترسی خواهیم داشت و سپس چک میکنیم که
اگر آن محصولی که در سشن ذخیره کرده بودیم، با مقدار آیدی این محصولی که الان داره به کاربر نمایش داده میشود، یکسان بود پس
کانتکس با نام ایز فیوریت، ترو میشود و در غیر این صورت فالس میشود؛ نکته دیگر این که چون دیتا بصورت یک رشته متنی در
دیتابیس ذخیره شده است، برای اینکه بتوانیم در گزاره شرطی نتیجه دلخواه خود را بدست بیاوریم، باید به استرینگ تبدیلش کنیم:

```
class ProductDetailView(DetailView):
    template_name = 'product_module/product_detail.html'
    model = Product

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        loaded_product = self.object
        request = self.request
        favorite_product_id = request.session.get('product_favorite')
        context['is_favorite'] = favorite_product_id == str(loaded_product.id)
        return context
```

حالا میرویم یک جایی در ویو هم آن را نمایش میدهیم:

```
{% if is_favorite %}
    <div class="col-md-12">
        <p>این محصول مورد علاقه من می باشد.</p>
    </div>
{% endif %}
```

نکته مهم: در کل برای ذخیره سازی اطلاعات بصورت آبجکت نباید از سشن ها استفاده کنیم، چون معمولا سشن ها باید سبک باشند و
دیتایی در آنها ذخیره میشود باید در حد یک آیدی، یک رشته متنی، یک بولین و در حد همین ها باشند. روش بهتر استفاده از دیتابیس
هست و باید یاد بگیریم دیتای خود را به بهترین حالت ممکن در دیتابیس ذخیره کنیم و با بهترین حالت ممکن و با بهترین پرفرمنس
آن را واکشی کنیم، خیلی بهتر از آن هست که بخواهیم دیتا را داخل سشن ذخیره کنیم.
