# User Customization

زمانی که اولین مایگریشن ایجاد میشود، یکسری جداول مربوط به کاربران، سطح دسترسی ها و ... ساخته میشوند.

## auth_user:

این جدول کاربران هست که خود جنگو در اختیار ما قرار میدهد و یکسری فیلد دارد، مثلا فیلد ایزسوپریوزر اگر مقدار 1 داشته
باشد، یعنی این کاربر دسترسی کامل به پنل ادمین را دارد، یا ایزاستف مثل همان سوپریوزر هست اما مشخص میکند کاربر، کارمند آن
سایت هست یا خیر، یعنی به بخش هایی از ادمین دسترسی خواهیم داشت یا خیر، که بیشتر با سیستم پرمیشن جنگو در ارتباط هست.

## account_module:

برای مدیریت اکانت ها و کاربران، میتوانیم یک اپ جدا ایجاد کنیم.

### get_user_model:

این گت یوزر یک فانکشن هست که میاد یوزر را به ما میدهد، یعنی عملا ما فیلد های جدول آتیوزر دسترسی داریم، مثلا در ویو:

```
from django.contrib.auth import get_user_model

user = get_user_model()

def user_view(request):
    first_name = user.first_name
```

## شخصی سازی کلاس یوزر

معمولا در پروژه های واقعی، ما میام و فیلد های کلاس یوزر را عوض میکنیم، ممکن هست ما بخواهیم احراز هویت با استفاده از
موبایل انجام شود و ایمیل برای ما مهم نیست، یعنی سیستم ثبت نام رو عوض کنیم و نیاز نداریم حالت پیش فرض جنگو باشد؛ برای این
کار چندین روش وجود دارد؛ یک اینکه بیام برای فیلد های اضافی کاربر، یک جدول جدید درنظر بگیریم که معمولا اسمش را
یوزرپروفایل قرار میدهند و یک کلاس مدل جدید میسازیم؛ یعنی به این شکل:

```
class UserProfile(models.Model):
    pass
```

و سپس یک رابطه ای ایجاد میکنیم بین این جدول و مدل یوزر خود جنگو

### AbstractUser:

1. اما روش بعدی، این هست که بیایم مدل اصلی یوزر را تغییر بدهیم، یعنی جدول یوزری ایجاد کنیم و از ابسترکت یوزر ارث بری
   کنیم؛ یعنی آن فیلد ها و پراپرتی هایی که بصورت پیش فرض داخل مدل اصلی یوزر استفاده شده داخل ابسترکت یوزر قرار داده شده
   است؛ پس در اینجا آن فیلد های قبلی رو خواهیم داشت و علاوه بر آن، فیلد ها خودمان هم میتونیم در کلاس خودمان اضافه کنیم:

```
class User(AbstractUser):
    mobile = models.CharField(max_length=20, verbose_name='تلفن همراه')
    email_active_code = models.CharField(max_length=100, verbose_name='کد فعالسازی ایمیل')

    class Meta:
        verbose_name = 'کاربر'
        verbose_name_plural = 'کاربران'

    def __str__(self):
        return self.get_full_name()
```

2. باید به جنگو بگیم که مدل اصلی ما چه چیزی هست، چون که از حالت پیش فرض تغییر داده ایم باید به ستینگ پروژه برویم و
   ماژولی که مدل اصلی یوزر را داخلش تعریف کرده ایم رو بهش معرفی کنیم:

`AUTH_USER_MODEL = 'account_module.User'`

3. باید یک مایگریشن جدید بزنیم؛ اما باید یک نکته ای رو مد نظر داشته باشیم که نباید اواسط کار روی پروژه بیایم و کلاس یوزر
   جدید و شخصی سازی شده را تعریف کنیم، چرا که از قبل از مدل اصلی یوزر، بارها در جاهای مختلف پروژه مثل جدول جنگو ادمین
   لاگ استفاده شده است، به همین دلیل باید از همان ابتدای کار که داریم پروژه را استارت میزنیم، باید مدل یوزر خود را
   بسازیم، یعنی قبل از اینکه مایگریشن رو بزنیم باید این کار را انجام دهیم؛ کاری که الان مجبوریم انجام دهیم، پاک کردن کل
   دیتابیس هست؛ سپس دوباره مایگریشن ایجاد میکنیم؛ یعنی اپ های خود به غیر از اکانت رو از داخل ستینگ موقتا کامنت میکنیم،
   همچنین یوآرال های آنها هم کامنت میکنیم و سپس میک مایگریشن میزنیم و سپس مایگریت، حال جداول ساخته میشوند، سپس اون اپ ها
   و یوآرال هایی که کامنت کرده بودیم را از حالت کامنت خارج کرده و سپس دوباره دستور مایگریت رو میزنیم.

4. الان جداول ما تغییر کرده اند، یعنی اون فیلد هایی که میخواستیم به مدل یوزر اضافه شده اند و میتونیم آن دیتایی که
   میخواهیم را در جدول یوزر درنظر بگیریم.

پس بطور خلاصه اگر اول پروژه هستیم و جدول یوزر خود را ایجاد کرده ایم، اول کار باید دستور میک مایگریشن رو بزنیم، و سپس
دستور مایگریت، که مدل یوزر ساخته شود و تغییرات اعمال شود، اگر هم که پروژه از قبل استارت زده شده، و حالا میخوایم مدل یوزر
را عوض کنیم، دو جا را باید اول غیر فعال کنیم، یعنی در اینستالد اپس، اپ هایی که مربوط به مدل یوزر نیستند را غیرفعال کنیم
یعنی کامنت میکنیم، سپس میریم سراغ فایل یوآرال های اصلی و آدرس هایی که مربوط به ماژول های مختلفی هستند رو کامنت میکنیم،
سپس اگر فایل مایگریشن هایی داخل فولدر مایگریشنز در اپ اکانت بود هم پاک میکنیم و سپس میریم در ترمینال و با دستور میک
مایگریشنز، مایگریشن اولیه را ایجاد میکنیم و سپس مایگریت میکنیم که تغییرات مدل یوزر اعمال شود، سپس مواردی که کامنت کردیم
رو از حالت کامنت خارج میکنیم، سپس دستور مایگریت رو میزنیم که مدل های قبلی که ساخته بودیم، برگردند.
