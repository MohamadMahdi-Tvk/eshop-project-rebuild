# Paging

در مورد کلاس بیس ویو ها از جنس لیست ویو صحبت میکنیم، ما یکسری آیتم هایی داشتیم که موارد مختلفی رو بهش پاس میدادیم، یکی
از موارد جدیدی که میخواهیم بررسی کنیم، اوردرینگ است، که میتونیم آیتم هایی که داریم رو اوردر کنیم، مثلا براساس قیمت اوردر
میکنیم؛ میتونیم براساس چند مورد هم اوردر کنیم یعنی بیاد اول براساس قیمت سپس براساس فیلد دیگری اوردر کنیم، که در این مورد
میتونیم در لیست آن فیلد ها را پاس بدهیم. در سیستم صفحه بندی هم خود جنگو سیستم خوبی را پیاده سازی کرده است و یک ساختار
ساده را پیاده سازی کرده و فقط برایش مشخص میکنیم که در هر صفحه چند تا آیتم نمایش داده شود و خودش صفحه بندی میکند؛ یکی از
آیتم هایی که لیست ویو ها دارند، پیجینیت بای هست، که یک عددی از ما میگیرد که یعنی چندتا آیتم در هر صفحه نمایش داده شود:

```
class ProductListView(ListView):
    template_name = 'product_module/product_list.html'
    model = Product
    context_object_name = 'products'
    ordering = ['-price']
    paginate_by = 1
```

حال در هر صفحه یک آیتم نمایش داده میشود و اگر بخواهیم بریم صفحه بعد، باید بصورت کوئری استرینگ صفحه را برایش مشخص کنیم؛
مثلا الان میخوایم صفحه دو را داشته باشیم:

`http://127.0.0.1:8000/products/?page=2`

پس عملا اگر ما داخل یوآرال، بیایم و مقدار پیج رو عوض کنیم، این سیستم صفحه بندی را اعمال میکند؛ اما اگر بخواهیم آن دکمه
های اعداد صفحه در صفحه نمایش داده شود، میتونیم از پیجینیتور استفاده کنیم، که اگر . بزنیم و از پیج رینج استفاده کنیم،
مثلا اگر از صفحه یک تا ده داریم، رینج یک و یازده رو برمیگرداند که یک تا ده را شامل شود؛ یا مثلا میتوانیم با هزپریویس یا
هزنکست بررسی کنیم که آیا صفحه قبل یا بعدی اگر وجود داشت چه عملکردی صورت گیرد:

```
<ul class="pagination">
    {% if page_obj.has_previous %}
        <li><a href="?page={{ page_obj.previous_page_number }}">قبلی</a></li>
    {% endif %}
    
    {% for pageNumber in paginator.page_range %}
        <li class="{% if page_obj.number == pageNumber %} active {% endif %}">
            <a href="?page={{ pageNumber }}">{{ pageNumber }}</a>
        </li>
    {% endfor %}
    
    {% if page_obj.has_next %}
        <li><a href="?page={{ page_obj.next_page_number }}">بعدی</a></li>
    {% endif %}
</ul>
```

در ال آی هم چک کردیم که اگر صفحه جاری با صفحه ای که الان در آن هستیم برابر بود، کلاس اکتیو برای دکمه آن صفحه فعال شود؛
پس پیج آبجکت.نامبر، صفحه جاری را برمیگرداند که اگر صفحه جاری با یکی از صفحات برابر بود آن کلاس اعمال شود.
