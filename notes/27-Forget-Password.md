نه، اگر این ایمیل وجود داشت، یک ایمیل برای کاربر ارسال میکنیم که داخلش یک لینک وجود دارد و چک میکنیم اگر اکتیو کد کاربر
درست بود؛ حال کاربر باید پسورد جدید و تکرار پسورد جدید خود را وارد کند تا فرآیند لاگین انجام شود. پس عملا ما چنین لینکی
را به ایمیل کاربر ارسال میکنیم:

`http://127.0.0.1:8000/reset-pass/3038cWSz16T7vgP3wcWWdygi4CYXAFp0AEBQciaS6tBgvpAeBhWpJQaaFTUwhkc3B6tQCt9N`

وقتی کاربر روی لینک کلیک کرد صفحه ی بازیابی کلمه عبور برایش باز میشود و میتواند پسورد جدید خودش را ایجاد کند.

## send email

برای ارسال ایمیل یک سرویس یا یوتیلیتی جدا ایجاد میکنیم، یعنی داخل روت پروژه یک ماژول جدید ایجاد میکنیم؛ یعنی روی اسم روت
کلیک راست کرده و گزینه پایتون پکیج رو انتخاب میکنیم و اسمش را یوتیلز میتونیم قرار بدیم؛ داخل این فولدر، یک فایل پایتون
ایجاد میکنیم و اسمش رو ایمیل سرویس قرار میدهیم و کد ارسال ایمیل به کاربر را اینجا مینویسیم؛ یک فانکشن ایجاد میکنیم که
ورودی سابجکت میگیرد که همان عنوان ایمیل است، ورودی دیگر کانتکس هست، یعنی دیتایی که قرار هست برای کاربر ارسال شود که همان
کانتکسی هست که در تمپلیت و ویو ادغام میشوند، یعنی عملا باید یک صفحه اچتی ام ال رو برداریم و یک کانتکس داخلش بریزیم، به
یک رشته متنی تبدیلش کنیم و در قالب بدنه ایمیل برای کاربر ارسال کنیم؛ ورودی دیگر هم تو هست که یعنی برای چه کسی ارسال
میشود و یک ورودی دیگر، تمپلیت نیم هست که اسم صفحه اچتی ام ال مد نظر است. اما برای ایجاد همچین فانکشنی، خود جنگو پکیج
هایی دارد که از آنها استفاده میکنیم و میتوان برای یک نفر یا یک گروه ایمیل ارسال کنیم:

```
from django.core.mail import send_mail
from django.template.loader import render_to_string
from django.utils.html import strip_tags


def send_email(subject, to, context, template_name):
    try:
        html_message = render_to_string(template_name, context)
        plain_message = strip_tags(html_message)
        from_email = ''
        send_mail(subject, plain_message, from_email, [to], html_message=html_message)
    except:
        pass

```

ما کد ارسال ایمیل رو پیاده سازی کردیم، اما این ایمیل چگونه و بوسیله چه اکانتی ارسال شود؟ ما در فایل ستینگز میتونیم
تنظیمات مربوط به ایمیل را انجام دهیم:

```
EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'
EMAIL_USE_TLS = True
EMAIL_HOST = 'smtp.gmail.com'
EMAIL_HOST_USER = ''
EMAIL_HOST_PASSWORD = ''
EMAIL_PORT = 587
```

برای اینکه بتوانیم از اکانت ایمیل ارسال کنیم, عبارت زیر رو باید در گوگل سرچ کنیم:

`less secure apps gmail`

سپس روی لینک زیر کلیک کرده:

`https://support.google.com/accounts/answer/6010255?hl=en`

و باید مراحل را طی کنیم تا قابلیت ارسال ایمیل از طریق اکانت خودمان فعال شود و سپس باید مقادیر ایمیل هاست یوزر را با آدرس
ایمیل خود و مقدار ایمیل هاست پسورد را با پسورد خود پر کنیم.
