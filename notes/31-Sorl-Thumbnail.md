# Sorl-Thumbnail Package

این پکیج جهت فشرده سازی و کراپ تصاویر مورد استفاده قرار میگیرد و به خوبی در پروژه ها میتونیم ازش استفاده کنیم. ما به
عنوان برنامه نویس باید بتوانیم چه اون عکسی که کاربر وارد میکند و چه ادمین سایت وارد میکند، تصاویر را از لحاظ سایزی
مدیریت کنیم، این پکیج به ما کمک میکند؛ هم میتونیم در کد های اچتی ام ال استفاده کنیم و هم در قسمت بک اند، یعنی عملا
میتونیم برای عکس بوسیله پایتون یک تامبنیل بسازیم؛ مثلا در ای پی آی ها ازش استفاده کنیم. داکیونت آن:

`https://sorl-thumbnail.readthedocs.io/en/latest/`

1. `pip install sorl-thumbnail`

2. به اینستالد اپس رفته و آن را اضافه میکنیم:

`'sorl.thumbnail'`

3. باید دیتابیس رو آپدیت کنیم؛ چون این پکیج در دیتابیس جدول میسازد، برای اینکه تصاویر را میسازد و آن هارا کش میکند؛ پس:

`python manage.py migrate`

4. در تمپلیتی که میخواهیم از آن استفاده کنیم باید ابتدا آن را در بالای صفحه لود کنیم، یعنی:

`{% load thumbnail %}`

5. اون تصویری که میخواهیم تامبنیل آن ساخته شود، باید رپ کنیم، یعنی تگ ایمیچ باید داخل دستور تامبنیل قرار گیرد:

```
{% thumbnail article.image "800x350" as im %}
    <img src="{{ im.url }}">
{% endthumbnail %}
```

6. اگر در مرورگر تگ عکس را مشاهده کنیم به این شکل تغییر کرده است:

`<img src="/medias/cache/9f/ac/9facb658935388f29acf2d2a7b3bd5ff.jpg">`

یعنی این عکس داره از آدرس دیگری میاد. و برای تنظیمات دیگر باید داکیومنت آن را مطالعه کنیم.

7. crop = 'center':

با این تنظیم، اون سایزی که ما میخواستیم رو جنریت میکند؛ یعنی:

```
{% thumbnail article.image "862x398" crop='center' as im %}
    <img src="{{ im.url }}">
{% endthumbnail %}
```

8. 862x398: این سایزی هست که طراح قالب درنظر گرفته است، پس میتونیم آن را در تامبنیل خود اختصاص دهیم

9. quality = 95: مقدار کیفیت را تنظیم میکنیم

```
{% thumbnail article.image "862x398" quality=95 crop='center' as im %}
    <img src="{{ im.url }}">
{% endthumbnail %}
```

این پکیج، به ازای هر عکسی که جنریت میکند، کش تامبنیل آن را میسازد، دیتای آن هم در دیتابیس ذخیره میکند، و در سری های
بعدی، بصورت کش شده دیتا را میاورد. ما هر عکسی که در صفحه داشته باشیم میاد تامبنیل آن را میسازد و موقع نمایش، تامبنیل رو
به کاربر نمایش میدهد و ما میتونیم برای جاهای مختلف اپلیکیشن این عکس رو استفاده کنیم، یعنی همین عکس ممکنه در صفحه ی اصلی
در یک باکس دیگری نمایش داده شود، مثلا برای صفحه محصولات هم میتونیم استفاده کنیم:

```
{% thumbnail product.image "268x250" quality=60 crop='center' as im %}
    <img src="{{ im.url }}">
{% endthumbnail %}
```
