# Jalali Date Package

# این پکیج با نسخه های جدیدتر پایتون مثل این پروژه ناهماهنگ است و اجرا نمیشود

این پکیج برای نمایش تاریخ بصورت شمسی است و میتوانیم در پروژه ها استفاده کنیم:

`https://pypi.org/project/django-jalali-date/`

# Custom Template Tags:

با قدم به قدم رفتن مراحل در داکیونت زیر میتونیم یک تمپلیت تگ بسازیم:

`https://docs.djangoproject.com/en/6.1/howto/custom-template-tags/`

تفاوت یک پایتون پکیج و یک پوشه یا دایرکتوری، وجود فایل زیر است:

`__init__.py`

پس اگر این فایل داخل فولدری باشد، به عنوان پکیج با آن پوشه برخورد میکند.
