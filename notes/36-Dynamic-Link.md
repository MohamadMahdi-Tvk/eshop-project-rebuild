# Dynamic Link

## request.resolver_match.url_name:

با این دستور میتونیم در ویو خود چک کنیم که اسم یوآرالی که برای آدرسی درنظر گرفته شده برابر با چه چیزی باشد، یعنی
ریزالورمچ میاد آدرس صفحه جاری را برمیگرداند؛ یکی از کاربرد های آن برای کلاس اکتیو هست، یعنی اگر یوآرال آن صفحه برابر بود
با یوآرالی که ما بهش میگیم، بیاد و آن کلاس اکتیو را به آن تگ اختصاص دهد:

```
<a href="{% url 'home_page' %}" class="{% if request.resolver_match.url_name == 'home_page' %}active{% endif %}">خـانه</a>
```

برای مابقی لینک ها هم همین دستور را قرار میدهیم و آدرس آن صفحه را برایش مشخص میکنیم.
