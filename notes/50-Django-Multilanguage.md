# Django Multilanguage

یکسری بخش های وب سایت هستند که نیاز هست آن ها را در دیتابیس بصورت چندزیانه درنظر بگیریم، اما بعضی از موارد هستند که اصلا
در دیتابیس ذخیره نمیشوند. یعنی هرچیزی رو نباید در دیتابیس ذخیره کرد. پس دو عامل رو باید درنظر بگیریم، اونهایی که هستند
که داخل دیتابیس ذخیره میشوند، یعنی دیتاهایی که از دیتابیس میاریم و نمایش میدهیم، و عامل دوم، موارد یا متن های استاتیکی
هستند که داخل خود سورس کد قرار داده شده اند. بطور مثال در یک کلاس مدل خاص که فیلد تایتل دارد، باید یک فیلد دیگر با نام
عنوان انگلیسی هم درنظر بگیریم. اما جنگو برای این کار، در دل خودش فریمورکی رو درنظر گرفته است؛ اگر به فایل ستینگز برویم،
موارد مربوط به چند زبانه کردن رو مشاهده میکنیم:

```
LANGUAGE_CODE = 'fa-ir'
TIME_ZONE = 'UTC'
USE_I18N = True
USE_L10N = True
USE_TZ = True
```

این قابلیت ها بطور پیش فرض باعث میشود، اگر مثلا یک کاربری از کشور دیگری وارد سایت ما شود، ساعت براساس ساعت کشور خودش
نمایش داده میشود.

باید حالت شیرد آن را نصب کنیم، لینک آن:

`https://mlocati.github.io/articles/gettext-iconv-windows.html`

برای ادامه کار یک پروژه جدید ایجاد میکنیم و طبق مقاله ای که لینک آن را گذاشتیم پیش می رویم.
