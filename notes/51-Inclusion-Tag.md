# Inclusion Tag

ما در پروژه ی خود برای صفحات پارشیال، از رندرپارشیال استفاده کردیم، اما خود فریمورک جنگو، در هسته ی خودش، قابلیتی را
دارد که به ما این امکان را میدهد خیلی راحت بتوانیم کاری که رندرپارشیال برای ما انجام میدهد را بوسیله امکانات خود جنگو
پیاده سازی کنیم؛ اما پکیج رندرپارشیال هم قابلیت های خوبی دارد، بطور مثال ما میتوانیم یک جدولی را در دیتابیس خود تعریف
کنیم، که رشته ای که به تمپلیت تگ رندر پارشیال میدیم رو در خودش ذخیره کند و برایش اولویت نمایش قرار بدهیم، بدین وسیله ما
میتوانیم از طریق پنل ادمین، اولویت نمایش آن پارشیال را عوض کنیم، این قابلیتی هست که رندرپارشیال برای ما فراهم میکند. اما
برای حالت فعلی که از رندپارشیال استفاده کردیم، جنگو برای ما این قابلیت را در دل خودش فراهم کرده است.

1. در اپ پروداکت ماژول، فولدر تمپلیت تگز را ایجاد میکنیم
2. داخل این فولدر باید یک اینکلوژن تگ بسازیم، داخل این فولدر یک فایل پایتونی به اسم پروداکت_تگز ایجاد میکنیم
3. سیستم اینکلوژن تگ، یک چیزی شبیه همان کامپوننت پروداکت_کتگوریز_کامپوننت است، با این تفاوت که ساختار رندر خود را بوسیله
   دکوریتور بالای فانکشن تعریف میکند و کانتکسش رو داخل بدنه فانکشن تعریف میکنیم و در نهایت آن کانتکس را ریترن میکنیم:

```
from django import template

from product_module.models import ProductCategory

register = template.Library()


@register.inclusion_tag('product_module/components/product_categories_component.html', takes_context=True)
def product_categories_inclusion(context, *args, **kwargs):
    request: HttpRequest = context.get('request')
    print(f"path is: {request.path}") # path is: /products/
    product_categories = ProductCategory.objects.filter(is_active=True, is_delete=False)
    return {'categories': product_categories}

```

4. برای استفاده از آن کافیست در بالای تمپلیت ویوی خود آن را لود کنیم:

`{% load product_tags %}`

و در جایی از ویو که میخواهیم باید اسم فانکشن را بنویسیم تا آن را رندر کند:

`{% product_categories_inclusion %}`

5. اگر داخل اینکوژن تگ خود، نیاز به کانتکس صفحه، رکوئست یا به کاربر جاری نیاز داشتیم میتوانیم تیکس_کانتکست را ترو قرار
   بدهیم و باید در ورودی فانکشن کانتکس را دریافت و در بدنه فانکشن از آن استفاده کنیم:

`takes_context = True`
