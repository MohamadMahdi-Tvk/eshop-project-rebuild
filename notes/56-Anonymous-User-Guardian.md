# Anonymous User - Guardian

ما میتوانیم برای کاربرانی که لاگین نکردند هم پرمیشن مشخص کنیم، بصورت پیش فرض جنگو در ریکوئست، یوزر را به ما به عنوان
برنامه نویس میدهد؛ حالا این کاربر یا لاگین هست یا لاگین نیست، بطور مثال در یکی از ویو ها میتوانیم این کد ها را قرار
دهیم:

```
print(f'user is authenticated: {self.request.user.is_authenticated}')
print(f'user is anonymous: {self.request.user.is_anonymous}')
```

ایزآنانیموس، برای گاردین نیست، بلکه برای خود جنگو است؛ اگر کاربر لاگین باشد، این پیغام در ترمینال چاپ میشود:

```
user is authenticated: True
user is anonymous: False
```

و اگر کاربری لاگین نباشد :

```
user is authenticated: False
user is anonymous: True
```

کاربری که ایزآنانیموس آن ترو هست، نمیشود برایش کاری انجام داد، آن، صرفا در جریان درخواستی که میاد در اپلیکیشن و
برمیگردد، ماهیتش ایجاد میشود و از بین میرود، یعنی عملا اگر بخواهیم برای یوزر مهمان یا یوزری که لاگین نکرده دسترسی درنظر
بگیریم، نمی توانیم روی ایزآنانیموس حساب باز کنیم، اما گاردین، میاد یک یوزر واقعی در جدول یوزر های ما ایجاد میکند با نام
کاربری آنانیموس یوزر، که نام کاربری آن هم میتوان تغییر داد. پیشنهاد میشود دست بهش نزنیم. اگر خواستیم جایی از آن استفاده
کنیم باید از ستینگز آن را ایمپورت کنیم، یعنی :

```
from django.conf import settings

settings.ANONYMOUS_USER_NAME
```

پس ما میتوانیم برای این آنانیموس یوزری که گاردین برای ما در جدول یوزرها ایجاد کرده دسترسی تعیین کنیم؛ برای این کار
کافیست مثلا یکی از محصولات را از پنل ادمین باز کنیم و سپس گزینه آبجکت پرمیشنز رو بزنیم و در قسمت یوزرآیدنتیفیکیشن اسم
آنانیموس یوزر را مینویسیم و روی منیج یوزر کلیک میکنیم:

`AnonymousUser`

و سپس دسترسی ها را از قسمت اجازه های موجود برایش تنظیم میکنیم. سپس برای استفاده کافیست مورد زیر را ایمپورت کنیم:

`from guardian.utils import get_anonymous_user`

و در ویوی مورد نظر چک میکنیم:

```
if self.request.user.is_anonymous:
    user = get_anonymous_user()
else:
    user = self.request.user
print(f'current user name is: {user.username}')
```

و به این روش باید از یوزر آنانیموس در ادامه فرآیند استفاده کنیم. حالا ما میتوانیم کوئری را به این صورت ویرایش کنیم:

```
from guardian.shortcuts import get_objects_for_user

query = get_objects_for_user(
    user=user,
    klass=query,
    perms=["view_product"],
    accept_global_perms=False
)
```
